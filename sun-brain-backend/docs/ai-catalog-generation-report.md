## Проверка качества

Использованы отдельное решение моделью без общей истории, точная рациональная проверка
арифметического выражения в Python, валидация безопасного SVG/XML и проверка дублей.
Среди отклонённых кандидатов были округлённые периодические дроби, неверные ответы,
противоречивые условия и неверно изображённые скрытые рёбра.

Агент отдельно отклонил одну задачу по графику: необходимые данные были только на изображении.
Замена содержит формулу в тексте. Промпты дополнены явным требованием самодостаточности текста.
Для задачи о дисперсии дополнительно перечислены все 64 последовательности бросков;
для трёх задач теории чисел выполнен независимый перебор целых чисел.

Автоматическая проверка не является формальным доказательством правильности произвольной
задачи. Модель проверки может разделять ошибки генератора; вычисление выражения проверяет
арифметику, но не доказывает его вывод из условия. В первой партии это дополнено просмотром
агента; будущие автоматические партии сохраняют описанное ограничение.
Темы с доказательствами и несколькими ответами представлены числовыми подзадачами согласно
выбранному ограничению на один конечный десятичный ответ. Номера тем — внутренние позиции каталога.
