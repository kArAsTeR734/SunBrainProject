# SunBrain
Проект SunBrain - образовательная платформа для подготовки обучающихся к ЕГЭ-ОГЭ по предметам Математика и Физика с автоматизированным процессом обучения и построением индивидуального плана ученика при помощи ИИ.
Платформа разрабатывалась на стеке:
Frontend: React/TypeScript, TanstackQuery, ReduxToolkit, react-hook-form, axios.
Backend: Node.js, Express.
