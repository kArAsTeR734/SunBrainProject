# Инструкции для работы с SunBrain

SunBrain — образовательная веб-платформа. Frontend находится в `sun-brain-frontend`, backend — в `sun-brain-backend`.
Перед изменениями изучайте соответствующий код и настройки проекта; не считайте README или этот файл заменой текущему
коду.

## Принципы работы

Всегда используйте `.agents/skills/karpathy-guidelines/SKILL.md` при выполнении задач.

Сохраняйте существующие изменения пользователя. Не добавляйте секреты и файлы окружения с реальными учётными данными в
репозиторий.

## Требования к разработке

Соблюдайте требования из `REQUIREMENTS.MD`.

## Документация и проверки

- Для документации библиотек, API, настройки и примеров используйте Context7, если он доступен. Учитывайте версии из
  соответствующего `package.json` и lock-файла; при недоступности Context7 обращайтесь к официальной документации и
  сообщайте об ограничении, если оно влияет на результат.
- Выбирайте проверки по затронутой области. Для frontend доступны `npm run lint` и `npm run build` из
  `sun-brain-frontend`; у backend в текущем `package.json` нет команд тестирования или линтинга. Не утверждайте, что
  проверка пройдена, если она не запускалась.

## Ветки Git

- Для каждой новой задачи создавайте отдельную ветку с префиксом `codex/` до внесения изменений.
- В коммит задачи включайте только её изменения. Сохраняйте незакоммиченные изменения из других задач отдельно, чтобы
  они не попадали в PR.
