# Проверки загрузки и каталога

Из каталога frontend выполните `npm ci`, затем `npx playwright install chromium` и `npm run test:performance`.

Если в Windows уже установлен Edge, вместо установки Chromium можно задать `$env:PLAYWRIGHT_CHANNEL="msedge"` в PowerShell перед запуском тестов.

Команда собирает frontend и поднимает отдельные серверы на портах 3002 и 3030. Эти порты должны быть свободны. Ответы API подставляются тестами, поэтому для этих браузерных проверок backend не требуется.

Проверяемые критерии:

- Главная production-сборки не запрашивает Markdown/KaTeX, их стили и шрифты. После перехода в каталог формулы отображаются.
- Действующий access-токен позволяет открыть каталог без refresh. Просроченный или повреждённый токен и сессия только с cookie восстанавливаются одним запросом. Публичная главная видна во время медленного refresh.
- Параллельные и запоздавшие 401 используют один refresh. Ошибка refresh очищает токен, повторный 401 после обновления завершает сессию без бесконечного цикла.
- Каталог показывает 12, затем 24 и 25 карточек. Ошибка следующей порции сохраняет предыдущие карточки и позволяет повторить загрузку. На последней порции кнопка исчезает, при смене темы выдача начинается заново.

Показатели запросов production-главной прикладываются к результату первого теста как `home-network.json`.
