# Каталог задач
## Требования к оформлению
1. Список тем должен формироваться на основе банка ФИПИ
2. Название для каждой темы задания из варианта ЕГЭ/ОГЭ должно соответствовать аналогичному названию из банка заданий ФИПИ
3. Если название не помещается, производится перенос строки внутри карточки
4. Пока список тем загружается должен показываться Loader
5. Если темы не были получены обработай этот сценарий и покажи пользователю ошибку при получении тем
6. Если тем по этому типу экзамена ещё нет, покажи Empty State

## Критерии выполнения
1. Все названия тем должны совпадать с названиями из банка ФИПИ, если это не так, исправляяй
2. Текст не должен выходить за границы карточки темы TaskTheme
3. Если возникла ошибка при получении тем, пользователь получает ошибку
4. Если тем нет, пользователю показывается Empty State
5. Если темы грузяться, пользователю показывается Loader
